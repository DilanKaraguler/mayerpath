# Data

`cb7.mol2` — cucurbit[7]uril, C42H42N28O14 (126 atoms), Tripos MOL2 format.
This is the structure used for the cucurbit[7]uril example of
R. Wang and G.-W. Wei, *Persistent path Laplacian*, Foundations of Data Science 5 (2023).
Only the element symbols and coordinates of the `@<TRIPOS>ATOM` block are read.
