## Example 5.1 (ex:lapvshom): same Betti numbers, different spectra

G_A: 0->1, 0->2, 0->3, 1->2, 3->2;  G_B: 0->2, 0->3, 1->0, 1->2, 3->2

| | dim Omega_0..3 (G_A) | dim Omega_0..3 (G_B) |
|---|---|---|
| | [4, 5, 2, 0] | [4, 5, 2, 0] |

| N, q | beta_0, beta_1, beta_2 (G_A) | beta_0, beta_1, beta_2 (G_B) |
|---|---|---|
| N=2, q=1 | [1, 0, 0] | [1, 0, 0] |
| N=3, q=1 | [2, 1, 0] | [2, 1, 0] |
| N=3, q=2 | [0, 3, 0] | [0, 3, 0] |

| Laplacian | G_A | G_B |
|---|---|---|
| L^2_{0,1} | {0, 2, 4, 4} | {0, 2, 4, 4} |
| L^2_{1,1} | {2, 2, 4, 4, 4} | {2, 2, 4, 4, 4} |
| L^2_{2,1} | {2, 4} | {2, 4} |
| L^3_{0,1} | {0, 0, 1, 5} | {0, 0, 2, 4} |
| L^3_{1,1} | {0, 0.1338, 2, 3.211, 4.655} | {0, 0.2679, 1.586, 3.732, 4.414} |
| L^3_{2,1} | {2, 4} | {2, 4} |
| L^3_{0,2} | {0.1338, 2, 3.211, 4.655} | {0.2679, 1.586, 3.732, 4.414} |
| L^3_{1,2} | {0, 0, 0, 2, 4} | {0, 0, 0, 2, 4} |
| L^3_{2,2} | {1, 5} | {2, 4} |
